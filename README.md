# NetMarket

Page d'accueil d'une marketplace fictive d'équipement réseau MikroTik (Burkina Faso et Afrique de l'Ouest), qui met en relation vendeurs, techniciens et clients.

Projet d'apprentissage : la maquette a été conçue avec Claude Design, puis codée en HTML, CSS et JavaScript, sans framework.

## Voir le site

Ouvrir `index.html` dans un navigateur.

## Fichiers

| Fichier | Rôle |
|---------|------|
| `index.html` | Structure de la page |
| `styles.css` | Apparence, responsive et mode sombre |
| `script.js` | Menu mobile, filtres et affichage des produits et techniciens |
